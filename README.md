# 台股 AI 自動進化雷達 v0.1

這是一個可直接部署成靜態網頁的台股研究工具。

## 功能
- 每個台灣交易日 18:10 自動執行。
- 官方 TWSE OpenAPI 抓上市股票。
- 官方 TPEx OpenAPI 抓上櫃股票。
- 每日快照累積至 `data/history.csv`。
- 20 個交易日後開始產生動能/量價/波動評分。
- 至少 45 個交易日後，每週五用已累積歷史做一次簡單演化式權重搜尋。
- `index.html` 直接讀取 `data/latest.json` 顯示排行。
- 資料不足時不硬產生假訊號。

## 直接本機測試
1. 安裝 Python 3.10+。
2. 在專案資料夾執行：`python scripts/fetch_and_score.py`
3. 再執行：`python -m http.server 8000`
4. 瀏覽器開 `http://localhost:8000`

> 不建議直接用 `file://` 雙擊 index.html，因為瀏覽器通常會限制它讀取本地 JSON。

## 真正每天自動
最省事的方法是放到 GitHub repository：
1. 將此資料夾內容上傳到 repo。
2. 到 Settings → Actions → General，允許 workflow 具有讀寫權限。
3. 到 Settings → Pages，選 Deploy from a branch，branch 選 `main` / root。
4. GitHub Actions 會在週一到週五台北時間 18:10 更新資料；GitHub Pages 網址就是你的固定儀表板。

## 模型說明
v0.1 是「可驗證的演化式評分器」，不是黑箱 AI：
- mom5：5 日價格動能
- mom20：20 日價格動能
- vol_ratio：當日成交量 / 過去 20 日均量
- volatility：近 20 日波動
- 初始權重固定；累積 45 日後，週五嘗試演化權重。
- 新權重只有在歷史樣本的相關性適應度更好時才取代舊權重。

## 下一版建議
加入三大法人、融資融券、除權息還原、產業分類、市場 regime、walk-forward 驗證、交易成本與最大回撤約束。這些比單純追求「預測準確率」更重要。

## 風險
本專案僅供量化研究與決策輔助，不構成投資建議。任何模型都可能因市場結構改變而失效。

## v0.3 新增
- 手機首頁：市場情緒、明日 AI 預測、昨日預測驗證、法人熱門板塊、AI 盤後總結。

- 正式自我進化仍需累積歷史資料；不以單日猜錯直接修改模型，以降低過度擬合。

## v0.4 — 60 交易日自動回補
這版新增 `scripts/backfill_60d.py` 與 GitHub Actions `Backfill 60 trading days`。
首次上傳到 GitHub 後，Actions 會透過 TWSE 官方歷史端點回補：
- 最近 60 個交易日：TAIEX 收盤、漲跌、外資/投信/自營商/三大法人總額。
- 最近 20 個交易日：全上市個股 OHLCV + 個股三大法人股數，用來啟動 5/20 日因子。
- 回補資料只作為模型訓練/回測，不會計入「真正事前預測」命中率。

目前 ZIP 內仍保留先前的 5 日 seed，因製作環境不能直接連官方 API；一旦 GitHub Action 首次成功執行，`market_60d.json` 與 `history_20d.csv` 會被正式資料覆蓋。
